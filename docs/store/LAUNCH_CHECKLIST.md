# Чек-лист запуска: то, что может сделать только владелец

Порядок важен: каждый пункт опирается на предыдущие. Значения в угловых скобках подставляет владелец; в репозитории настоящих значений нет. Код и тексты, на которые ссылается список, уже в репозитории (`docs/store/`).

## 0. Решения, без которых дальше нельзя

- [x] Исправления `app.json` из `PRESUBMISSION_AUDIT.md` (находки 1–4: микрофон, фоновый звук, Face ID, `SYSTEM_ALERT_WINDOW`) внесены в Phase 7. Проверить на устройстве: запись голосового сообщения, камера, галерея, push.
- [ ] **Пакет Android:** остаётся ли `app.bloomly.mobile` или нужен `fun.bloomly.app.online` (то, что уже есть в `assetlinks.json` на сервере). После первой публикации в Google Play `applicationId` менять нельзя.
- [ ] **Возраст:** минимальный возраст 13 лет (Условия) против рейтинга 17+ из-за контента 18+ (`AGE_RATING.md`). Решение определяет анкеты рейтинга и тексты.
- [ ] **Sentry:** включать ли мониторинг ошибок в первой версии (нужны проект Sentry и регион данных; без DSN всё выключено).
- [ ] **Бэкенд-доработки** (тексты промтов готовит ассистент, нужно ваше «да» и срок хранения данных после удаления аккаунта): цели жалоб `comment` и `story`, согласие родителя из приложения, физическая очистка данных после удаления.

## 2. Сборка и проверка на телефоне

- [ ] `eas login`, затем сообщить ассистенту: он выполнит `eas init` (запишет `projectId`) и `eas build -p android --profile preview` (ключ подписи для preview EAS создаёт сам).
- [ ] Установить APK и пройти список проверок на устройстве. Он собран из разделов «Не проверено на устройстве» файла `docs/ARCHITECTURE.md`. Ключевое: вход (почта, OAuth, 2FA), регистрация и экран возраста, создание поста (фото, видео, камера, большой файл свыше 50 МБ), голосовое сообщение, чат и возврат из фона, push (получение, нажатие), ссылка `https://bloomly.fun/...` из мессенджера, офлайн-плашка и чтение ленты, удаление аккаунта, жалоба и блокировка, сплэш, FlashList (плавность, чат).
- [ ] Всё найденное прислать скриншотом и текстом ошибки: ассистент составит точечное исправление.

## 3. Универсальные ссылки (см. `DEEPLINKS.md`)

- [ ] **Android:** загрузить первую сборку (`.aab`) во внутреннее тестирование Google Play. Play Console → Приложение → Целостность приложения → Подпись приложения → «Сертификат ключа подписи приложения» → скопировать отпечаток **SHA-256** (не ключ загрузки из EAS: Play переподписывает сборки). Прислать ассистенту: он **допишет** запись для пакета в существующий `assetlinks.json`, не заменяя имеющуюся.
- [ ] **iOS:** после появления аккаунта Apple Developer прислать **Team ID**; ассистент подготовит `apple-app-site-association` для размещения на сервере (`/.well-known/`, без редиректов, `application/json`).
- [ ] Проверка после выкладки: инструкции в конце `DEEPLINKS.md`.
