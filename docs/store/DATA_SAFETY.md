# Google Play: раздел «Безопасность данных» (черновик)

Основа: что приложение **реально** собирает или отправляет (проверено по коду `app/`, `src/`, `app.json`, `package.json`). Приложение отправляет данные только на собственный сервер (`https://bloomly.fun/api`, WebSocket `/api/`) и в службу push Expo. Сторонних SDK аналитики, рекламы, отчётов о сбоях нет (в `package.json` их нет).

Сквозные ответы: данные шифруются при передаче — **да** (только HTTPS/WSS); пользователь может запросить удаление — **да** (в приложении: Настройки → Удалить аккаунт); данные передаются третьим сторонам для рекламы — **нет**; обязательные для работы данные обозначены ниже.

## Собираемые данные

| Тип данных (Play) | Что именно | Откуда в коде | Обязательно | Цель | Передаётся третьим лицам |
|---|---|---|---|---|---|
| Личная информация → Адрес электронной почты | email аккаунта | регистрация, вход, сброс пароля (`session.ts`) | да | Функциональность приложения, Управление аккаунтом | нет |
| Личная информация → Имя | отображаемое имя, username | онбординг, профиль | да (username) | Функциональность приложения | нет (публично видно другим пользователям) |
| Личная информация → Идентификаторы пользователя | id аккаунта | везде | да | Функциональность приложения | нет |
| Личная информация → Другое | дата рождения, email родителя (для 13–15 лет), отметки согласий, симпатии и антипатии профиля, местоимения | регистрация, возрастной экран, онбординг | дата рождения — да | Функциональность приложения, Соблюдение правового регулирования (проверка возраста) | нет |
| Сообщения → Другие сообщения в приложении | личные и групповые сообщения | чаты | нет (по использованию) | Функциональность приложения | нет |
| Аудио → Голосовые записи | голосовые сообщения, запись с микрофона только по нажатию | `app/messages/[id].tsx`, `useMessages.ts` | нет | Функциональность приложения | нет |
| Контент приложения → Другой пользовательский контент | посты, комментарии, реакции, жалобы, блокировки, подписки, участие в группах и событиях | лента, пост, профиль | нет | Функциональность приложения, Персонализация | нет |
| Действия в приложении → Взаимодействие с приложением | просмотры постов, оценки, подписки (на сервере для персонализированной ленты) | эндпоинты ленты и постов | нет | Персонализация, Функциональность приложения | нет |
| Идентификаторы устройства или другие → Идентификаторы устройства | Expo push-токен и платформа (iOS/Android) | `src/lib/push.ts` → `POST /push/expo-token` | нет (только если разрешены уведомления) | Функциональность приложения (доставка уведомлений) | да: Expo (служба push) и FCM/APNs как обработчики доставки |
| Информация о приложении и производительность | не собираются: отчётов о сбоях и диагностики в приложении нет | — | — | — | — |

Сервер самостоятельно сохраняет в записи сессии (refresh-токен): название устройства (из User-Agent), IP-адрес, идентификатор устройства, если клиент его прислал (`device_id`). Приложение `X-Device-Id` пока **не отправляет** (в `src/api/client.ts` его нет), поэтому на практике сервер видит только User-Agent и IP. Для формы Play это «IP-адрес, данные об устройстве: собирается автоматически сервером для безопасности и входа»: проверить формулировку по политике конфиденциальности.

## Не собираются

Геолокация (точная и примерная), контакты, календарь, SMS и журнал вызовов, фото и видео из галереи, камера, файлы и документы, данные о здоровье и спорте, финансовая информация и платежи (в версии 1.0 платежей нет), история поиска и просмотров вне приложения, рекламный идентификатор, биометрия.

## Требует внимания до отправки

- В `app.json` подключён плагин `expo-image-picker`, а в коде галерея и камера **не используются**. Плагин добавляет разрешения на камеру и фото в манифест; Play и Apple могут запросить пояснения. Убрать плагин, пока функция не реализована (по правилам проекта `app.json` не менялся без просьбы).
- Политика конфиденциальности: https://bloomly.fun/privacy (содержит плейсхолдер почтового адреса компании, см. REVIEW.md).
- Если появится загрузка медиа в посты, камера или аналитика — обновить таблицу.
