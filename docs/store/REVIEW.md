# Bloomly Mobile: памятка для рецензента магазина

Черновик для полей «App Review Information» (App Store Connect) и «App access» (Play Console). Настоящих учётных данных здесь нет: создать вручную перед отправкой и вписать в консоль магазина, не в репозиторий.

## Демо-аккаунт (создать вручную)

- [ ] Зарегистрировать аккаунт через приложение (email + пароль): `ЛОГИН-ДЛЯ-РЕЦЕНЗЕНТА` / `ПАРОЛЬ-ВПИСАТЬ-В-КОНСОЛЬ`.
- [ ] Подтвердить email, пройти онбординг, указать дату рождения 18+ (иначе режим «18+» недоступен).
- [ ] Лучше **без двухфакторной аутентификации**, чтобы рецензент вошёл без доступа к вашему аутентификатору или почте.
- [ ] Наполнить: 1–2 поста, комментарий, диалог со вторым тестовым аккаунтом (нужен для проверки жалобы на сообщение и блокировки).
- [ ] Вход через соцсети (Google, Яндекс, X, Twitch) для рецензента не нужен; он доступен на экране входа.

## Что проверять и где это находится

| Требование | Где в приложении |
|---|---|
| Согласие с условиями и политикой при регистрации | Вход → «Регистрация»: флажок «Я принимаю Пользовательское соглашение и Политику…» со ссылками; без него отправить форму нельзя |
| Возрастной порог | Регистрация: дата рождения; младше 13 лет — отказ; 13–15 — нужен email родителя (согласие родителя даётся по ссылке из письма на сайте) |
| Подтверждение 18+ и NSFW | Настройки → «Контент 18+». По умолчанию контент 18+ скрыт, режимы «размыт» и «показан» доступны только подтверждённым совершеннолетним (проверка на сервере по дате рождения) |
| Жалоба на контент | Значок «⋯» у поста, комментария, сообщения (чужого), профиля и группы → «Пожаловаться» → причина → «Отправить» |
| Блокировка пользователя | Тот же «⋯» → «Заблокировать @имя»; снятие — там же. В профиле — «⋯» рядом с кнопкой подписки |
| Удаление аккаунта | Профиль → значок «Настройки» → «Опасная зона» → «Удалить мой аккаунт» (подтверждение паролем и/или кодом, слово «УДАЛИТЬ») |
| Условия, политика, DMCA, поддержка | Настройки → «Правовая информация»; ссылки на условия и политику есть и на экране входа без авторизации |
| Контакт для модерации и жалоб | Настройки → «Правовая информация» → «Поддержка» (почта) |
| Покупки | **Нет.** Платежей, подписок и пополнения кошелька в приложении v1.0 нет. Магазин и Dealers' Den не открыты |

## Модерация (для описания в консоли)

- Жалобы уходят в очередь модерации (`POST /admin/reports`), рассматриваются модераторами на сайте.
- Блокировка пользователя скрывает его контент и закрывает личные сообщения.
- Автомодерация и санкции описаны в Условиях (раздел «Модерация и санкции»).

## Известные ограничения (честно сообщить при вопросах рецензента)

- Жалоба на комментарий уходит на его автора с цитатой: отдельной цели «comment» в бэкенде нет. Жалобы на истории (stories) в приложении нет, историй нет в интерфейсе приложения.
- В Условиях и Политике на сайте остался плейсхолдер почтового адреса компании (`frontend/src/lib/legal.ts`, поле `postalAddress`). **Заменить до отправки.**
- Удаление аккаунта на сервере сейчас выполняется как мягкое (аккаунт скрывается, сессии отзываются), физическая очистка данных в бэкенде не найдена. Текст на экране нейтральный: «Аккаунт будет удалён, сессии завершены. Часть данных может храниться согласно политике конфиденциальности»; срок и объём хранения должна описывать политика.
- Двухфакторная аутентификация поддерживается (приложение-аутентификатор и код на почту); иной способ второго фактора приложение не знает и сообщает об этом.
