# Иконки и сплэш: проверка файлов в `assets/`

Проверено скриптом по пикселям (размер, формат, альфа-канал, границы содержимого). Картинки не менялись и не генерировались. Требования магазинов указаны как правила проверки: актуальные значения сверить в App Store Connect и Play Console перед отправкой.

## Результат по файлам

| Файл | Где используется | Размер / формат | Вывод |
|---|---|---|---|
| `icon.png` | `expo.icon`, иконка iOS | 1024×1024, PNG, **RGB без альфа-канала** | Соответствует: iOS не принимает иконку с прозрачностью. Углы залиты тем же цветом, что и края (скругление не «запечено»), система скруглит сама |

| `android-icon-background.png` | adaptive icon, задний слой | 512×512, RGBA, **полностью непрозрачный** | Соответствует: фон адаптивной иконки не должен просвечивать |

## Расхождения и вопросы (нужно решение владельца)

1. ~~Сплэш не настроен~~ — **исправлено в Phase 6**, см. «Сплэш» ниже. (Прежняя запись этого файла ошибочно называла `splash-icon.png` залитым светло-серым кругом: на самом деле это была шаблонная сетка-заглушка Expo, не логотип.)
2. Ошибочный пункт об обрезке иконки сплэша снят по той же причине: файл заменён.
3. **Светлая иконка при тёмном приложении.** Иконка и фон адаптивной иконки светло-пастельные (около `#E6F4FE`), тёмная тема приложения и фон сплэша `#16192F`. Это не ошибка требований, но при смене сплэша на тёмный фон стоит проверить, что светлая иконка и тёмный запуск выглядят согласованно. Бренд-гайд (`docs/brand-guide.jpg`) сверить с владельцем.
4. **iOS: варианты иконки для тёмной темы и тонированная иконка** (iOS 18+) не подготовлены. Не обязательны, но без них система покажет обычную иконку. По желанию.
5. **Разрешение слоёв Android:** 512 px для переднего и заднего слоя достаточно (слой 108 dp при xxxhdpi — 432 px), запас есть. Рекомендация Expo — 1024 px; не критично.
6. **Альфа переднего слоя** нигде не достигает 255 (максимум 252): рисунок чуть полупрозрачный. Едва заметно; если цвета на устройстве выглядят блеклыми, исправить в исходнике.

## Сплэш (Phase 6)

**Требования** (проверены по официальным страницам; запомнить значения для следующей проверки: Android меняет их между версиями):
- Android 12+ ([developer.android.com, Splash screen](https://developer.android.com/develop/ui/views/launch/splash-screen)): иконка без подложки — холст **288×288 dp**, рисунок должен помещаться в круг **диаметром 192 dp** (всё снаружи маскируется, то есть видна 2/3); с подложкой — 240×240 dp и круг 160 dp. Фон окна — один непрозрачный цвет. Если иконка сплэша не задана, показывается иконка приложения.
- Плагин `expo-splash-screen` ([docs.expo.dev](https://docs.expo.dev/versions/latest/sdk/splash-screen/)): `image` без значения по умолчанию, `imageWidth` по умолчанию 100, `backgroundColor` по умолчанию `#ffffff`, `resizeMode` — `contain`, `cover` или `native`, есть `dark`. Документация предупреждает, что Expo Go и dev-сборки не отражают параметры плагина полностью: проверять на релизной сборке. Рекомендуемого размера в пикселях страница не называет.

**Что сделано:**
- `scripts/make-splash.mjs` вписывает существующий `assets/bloomly-logo.png` (цветок, фон прозрачный) в прозрачный холст 1024×1024: окружность, описанная вокруг рисунка, равна 60 % холста (порог Android 66,7 %). Рисунок не менялся, только масштаб и положение; результат — `assets/splash-icon.png` (рисунок 600×600 px, радиус 30,1 % при пороге 33,3 %).
- В `app.json` плагин: `backgroundColor: #16192F` (то же, что `colors.bg` в `src/theme/tokens.ts`; `npm run check` сверяет их), `image: ./assets/splash-icon.png`, `imageWidth: 288`, `resizeMode: contain`. Холст 1024 px ↔ 288 dp: на Android 12+ логотип занимает 173 dp из допустимых 192 dp, на iOS и до Android 12 — 288-пунктовый квадрат по центру. Отдельного тёмного варианта нет: приложение только тёмное.

**Проверено** генерацией нативных проектов во временной копии (`expo prebuild --no-install`, репозиторий не засорялся):
- Android: `windowSplashScreenBackground = #16192F`, `windowSplashScreenAnimatedIcon = splashscreen_logo`, `drawable-xxxhdpi/splashscreen_logo.png` 1152×1152 (288 dp × 4) с логотипом в радиусе 30 % от центра, то есть внутри круга 192 dp.
- iOS: цвет `SplashScreenBackground` равен `#16192F`, изображение 288×288 pt по центру (`scaleAspectFit`).

**Не проверено на устройстве:** вид сплэша на реальных Android 12+, Android 11 и ниже, iPhone; переход от сплэша к приложению; цвет контура лепестков (тёмно-фиолетовый) на фоне `#16192F` может оказаться малоконтрастным: оценить глазами. При необходимости менять `CIRCLE_RATIO` в скрипте, а не рисунок.
