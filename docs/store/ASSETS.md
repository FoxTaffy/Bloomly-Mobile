# Иконки и сплэш: проверка файлов в `assets/`

Проверено скриптом по пикселям (размер, формат, альфа-канал, границы содержимого). Картинки не менялись и не генерировались. Требования магазинов указаны как правила проверки: актуальные значения сверить в App Store Connect и Play Console перед отправкой.

## Результат по файлам

| Файл | Где используется | Размер / формат | Вывод |
|---|---|---|---|
| `icon.png` | `expo.icon`, иконка iOS | 1024×1024, PNG, **RGB без альфа-канала** | Соответствует: iOS не принимает иконку с прозрачностью. Углы залиты тем же цветом, что и края (скругление не «запечено»), система скруглит сама |
| `android-icon-foreground.png` | adaptive icon, передний слой | 512×512, RGBA | Соответствует безопасной зоне: содержимое занимает радиус 28,1 % ширины, граница безопасной зоны адаптивной иконки — 30,6 % (66 dp из 108 dp). Запас небольшой, но содержимое при любой маске не обрежется |
| `android-icon-background.png` | adaptive icon, задний слой | 512×512, RGBA, **полностью непрозрачный** | Соответствует: фон адаптивной иконки не должен просвечивать |
| `android-icon-monochrome.png` | тематическая иконка Android 13+ | 432×432 (108 dp × 4), RGBA | Соответствует: слой есть, содержимое в безопасной зоне (радиус 27,7 %). Размер отличается от остальных слоёв (432 против 512): на работу не влияет |
| `splash-icon.png` | заготовка сплэша | 1024×1024, PNG с палитрой, прозрачные углы | **Есть замечания, ниже** |
| `favicon.png` | только web-сборка Expo | 48×48 | Для магазинов не нужен |
| `bloomly-logo.png` | логотип на экране входа | 667×667, RGBA | Используется в приложении, к иконкам не относится |

## Расхождения и вопросы (нужно решение владельца)

1. **Сплэш не настроен в `app.json`.** Плагин `expo-splash-screen` подключён без параметров (его добавил `expo install --fix`), ни `image`, ни `backgroundColor` у плагина не заданы, поэтому `splash-icon.png` сейчас, скорее всего, не используется, и при запуске будет сплэш по умолчанию. Менять `app.json` в этой фазе разрешено только для версий, поэтому правка отложена: нужно указать в плагине `image: ./assets/splash-icon.png`, `backgroundColor` (по теме приложения `#16192F`) и `imageWidth`. Проверить результат в сборке.
2. **`splash-icon.png` занимает весь холст** (содержимое от края до края, на фоне непрозрачная заливка светло-серого цвета). На Android 12+ система показывает иконку сплэша внутри круглой маски: видна центральная часть примерно в две трети, остальное обрежется. Для сплэша нужен вариант, у которого рисунок лежит в центре и занимает не больше 60 % холста на прозрачном фоне. Генерировать картинки я не должен, нужен макет от дизайнера.
3. **Светлая иконка при тёмном приложении.** Иконка и фон адаптивной иконки светло-пастельные (около `#E6F4FE`), тёмная тема приложения и фон сплэша `#16192F`. Это не ошибка требований, но при смене сплэша на тёмный фон стоит проверить, что светлая иконка и тёмный запуск выглядят согласованно. Бренд-гайд (`docs/brand-guide.jpg`) сверить с владельцем.
4. **iOS: варианты иконки для тёмной темы и тонированная иконка** (iOS 18+) не подготовлены. Не обязательны, но без них система покажет обычную иконку. По желанию.
5. **Разрешение слоёв Android:** 512 px для переднего и заднего слоя достаточно (слой 108 dp при xxxhdpi — 432 px), запас есть. Рекомендация Expo — 1024 px; не критично.
6. **Альфа переднего слоя** нигде не достигает 255 (максимум 252): рисунок чуть полупрозрачный. Едва заметно; если цвета на устройстве выглядят блеклыми, исправить в исходнике.
